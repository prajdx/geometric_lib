# Вычислитель <ins>площади и периметра</ins> геометрических фигур

### На данный момент доступны функции для фигур:
- круг *(circle)*
- квадрата *(square)*


## Математические формулы:
    
### Круг *(circle)*
- <ins>Площадь</ins>: **S = πR²**
- <ins>Периметр</ins>: **P = 2πR**

### Квадрат *(square)*
- <ins>Площадь</ins>: **S = a²**
- <ins>Периметр</ins>: **P = 4a**
